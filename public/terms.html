2. Description of Service

Panda JL Studio is a client-side web application designed to merge and manage SQLite database backups. All processing occurs locally in your web browser. Optional Google Drive synchronization is provided solely to access your own backups stored in a dedicated application folder, including a private metadata index (.jlib_archive_index.json) containing SHA-256 checksums to facilitate duplicate prevention, backup presence verification across features, and cross-device sync alerts.
